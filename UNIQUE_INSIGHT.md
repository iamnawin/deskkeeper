# Unique Insight

## The Key Insight

Most productivity tools start with task execution: "Tell me what to do, and I will do it."

DeskKeeper starts with **task continuity**: "You are already doing things. I will watch them and tell you when they need you back."

This is the difference between:
- **Execution-first**: Create task → assign → track → remind
- **Continuity-first**: Work is already happening → watch its state → surface when attention is needed

---

## Why This Matters

Users do not forget to start tasks. They forget to **return to them** after shifting focus.

The broken loop is:
1. Start a task (open window, run a command, start an upload)
2. Shift focus to another task
3. The original task changes state (fails, completes, stalls, waits)
4. User never returns
5. Work is lost, delayed, or forgotten

DeskKeeper closes this loop **without changing the user's workflow**. The user does not need to adopt a new system. They just need to be told when something already in motion needs them back.

---

## The Attention Recovery Insight

Attention recovery is a different problem than attention management.

- Attention management: scheduling, prioritization, focus blocks
- Attention recovery: "What did I leave open that is now waiting for me?"

No existing category owns attention recovery. This is DeskKeeper's wedge.

---

## The Forgotten State Problem

The specific failure DeskKeeper solves: **forgotten open work**.

A window does not need to be closed to be forgotten. A task does not need to be cancelled to be abandoned. The failure mode is quiet. The window is still open. The task is still running. The user is simply no longer looking.

DeskKeeper detects this state and surfaces it.

---

## Competitive Moat

DeskKeeper's advantage is not the algorithm. It is the **local-first, cross-app, multi-screen scope** combined with a **privacy-safe, user-controlled detection model**.

Agents that act on your desktop will face constant privacy and trust concerns. DeskKeeper only watches — and only what you tell it to watch. That is a fundamentally safer and more adoptable model.
