## Project Context

DeskKeeper AI is a desktop control tower for unfinished work across screens, apps, tabs, tools, uploads, drafts, forms, renders, terminals, and AI agents. It solves attention fragmentation in multi-screen workflows.

The MVP should not be a full autonomous AI agent. It should be a privacy-first, local-first desktop app that monitors user-selected windows and alerts the user when something needs attention.

## Initial MVP

- Windows-first desktop app
- Electron + React + TypeScript + Vite + Tailwind
- List open windows
- User selects windows to watch
- Create task cards from watched windows
- Detect basic states using window title + rule-based detection
- Show desktop notifications
- Let user mark tasks done/snoozed/ignored
- Local storage
- Privacy controls
