# Settings Wireframe

```
┌─────────────────────────────────────────────────────────────────┐
│  DeskKeeper  ●  Monitoring Active                      [⏸ Pause]│
├────────────┬────────────────────────────────────────────────────┤
│            │                                                     │
│ Dashboard  │  Settings                                          │
│            │                                                     │
│ Watched    │  ── Notifications ──────────────────────────────── │
│ Windows    │                                                     │
│            │  Enable notifications              [● ON  ]        │
│ Rules      │  Notify when waiting for input     [● ON  ]        │
│            │  Notify when task fails            [● ON  ]        │
│ Settings   │  Notify when task completes        [○ OFF ]        │
│            │  Notification cooldown             [  5  ] min     │
│ ──────     │                                                     │
│            │  ── Monitoring ─────────────────────────────────── │
│ ⏸ Pause   │                                                     │
│ 🔒 Private │  Pause monitoring                  [○ OFF ]        │
│            │  Private mode                      [○ OFF ]        │
│            │  Capture interval                  [ 10  ] seconds │
│            │                                                     │
│            │  ── AI ─────────────────────────────────────────── │
│            │                                                     │
│            │  Use AI for ambiguous detection    [○ OFF ]        │
│            │  When enabled, window title snippets               │
│            │  may be processed by an AI model.                  │
│            │                                                     │
│            │  ── Data ───────────────────────────────────────── │
│            │                                                     │
│            │  [  Clear all local data  ]                        │
│            │  ⚠ This will remove all watched windows,           │
│            │    task cards, and notification history.           │
│            │                                                     │
└────────────┴────────────────────────────────────────────────────┘
```
