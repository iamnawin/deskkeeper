# Competitor Notes

## Quick Reference

See `COMPETITOR_ANALYSIS.md` for the full analysis.

## Key Takeaways

1. **Desktop agents** (Claude Computer Use, Manus, OpenAI Operator) — all execution-first. None watch live task state passively.
2. **Browser tools** (Browser Use, browser agents) — browser-only. Blind to desktop apps, terminals, native software.
3. **RPA tools** (UiPath, Power Automate) — enterprise, scripted. Not reactive to emergent work state.
4. **Productivity tools** (Todoist, Notion, Motion) — require manual task entry. Don't detect live window state.
5. **Per-app notifications** (Vercel, GitHub, Slack alerts) — siloed. No unified cross-app view.

## The Gap DeskKeeper Fills

No tool today:
- Passively monitors open windows across all apps
- Works locally without cloud
- Watches emergent work state (not pre-planned tasks)
- Unifies signals from terminals, browser, native apps
- Tells the user "what needs attention" across everything

## Products to Watch

- **Alfred** — similar concern on macOS.
- **Notion AI** — could expand into ambient work tracking.
- **Arc Browser** — building more "workspace awareness" features.
- **Electron-based productivity apps** — if big players add window monitoring to existing apps.
