# User Personas

## 1. The Developer

**Name**: Arjun, 29, Senior Engineer  
**Environment**: 2 monitors, 6+ terminal windows, VS Code, GitHub, Vercel, local servers  
**Daily pain**: AI coding agents pause for approval while he's focused elsewhere. Builds fail silently. Deployments complete and he forgets to test them.  
**DeskKeeper value**: Knows immediately when Codex/Claude Code needs approval, when a build fails, when a deploy completes.  
**Quote**: "I don't need another tool to manage. I need something that tells me when my other tools need me."

---

## 2. The AI Creator

**Name**: Priya, 32, Freelance Video Creator  
**Environment**: 3 monitors, Runway, Veed, ElevenLabs, Canva, YouTube Studio open simultaneously  
**Daily pain**: Renders complete while she's working on a script. Downloads pile up. YouTube uploads stay unpublished.  
**DeskKeeper value**: Gets notified when renders finish, when exports are ready, when uploads need final publish action.  
**Quote**: "I lose 30 minutes a day just checking whether something finished or not."

---

## 3. The Founder / Operator

**Name**: Naveen, 34, Solo Founder  
**Environment**: MacOS / Windows, 2+ screens, Gmail, CRM, Notion, Vercel, terminal, Slack  
**Daily pain**: Proposal emails sit as drafts. CRM updates get forgotten after calls. Deployments fail overnight.  
**DeskKeeper value**: Surfaces unsent emails, missing CRM updates, failed deployments, open approvals.  
**Quote**: "I'm the entire operations team. I need a control tower, not another checklist."

---

## 4. The Business User

**Name**: Sarah, 42, Account Manager  
**Environment**: Windows laptop, dual monitor, Gmail, Salesforce, Excel, Zoom  
**Daily pain**: Drafts sit unsent. Forms expire mid-fill. Meeting follow-ups never happen because the window is still open but forgotten.  
**DeskKeeper value**: Reminders for unsent drafts, open form states, post-meeting follow-up prompts.  
**Quote**: "I have so many things open I sometimes can't tell what's done and what isn't."

**Environment**: Laptop, VS Code, course platform, assignment submission portal, browser research  
**Daily pain**: Leaves assignment submission pages open and forgets to submit. Code changes not pushed. Quizzes left unfinished.

## 7. The Remote Worker

**Name**: James, 38, Remote Consultant  
**Environment**: Home office, 3 screens, Slack, Notion, Zoom, client portals, CRM, email
