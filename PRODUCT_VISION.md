# Product Vision

## Long-Term Vision

DeskKeeper becomes the **attention operating system** for knowledge workers — a persistent layer that knows the state of everything you are working on across all apps, devices, and screens, and surfaces what needs you next.

The long-term state: you never have to wonder "what did I forget?" DeskKeeper always knows.

---

## Product Category

DeskKeeper sits at the intersection of:
- Desktop monitoring / work intelligence
- Attention management
- Task continuity

Best positioning: **Desktop control tower for unfinished work.**

Not a to-do list. Not a scheduler. Not a full desktop agent. A **state watcher** for work already in motion.

---

## Positioning

| Dimension | DeskKeeper |
|---|---|
| Core job | Surface what needs attention |
| Detection method | Window state + rules + optional AI |
| Privacy stance | Local-first, user-selected, no cloud default |
| Autonomy level | Observe and notify — never act without consent |
| Competitor gap | No tool today watches live multi-app work state locally |

---

## Phase by Phase Future

**Phase 1 — MVP (DeskKeeper Lite)**  
Windows desktop app. Rule-based detection. Notifications. Local storage.

**Phase 2 — Smarter Detection**  
Add OCR to read visible text from windows. More accurate state detection.

**Phase 3 — Chrome Extension Companion**  
Extension that surfaces browser-specific signals (form state, upload status, tab title) and feeds them into the desktop app.

**Phase 4 — Optional AI Classifier**  
Local or cloud AI to improve ambiguous detection. User-opt-in only.

**Phase 5 — Multi-Platform**  
macOS support. Linux support (limited).

**Phase 6 — Agent Watcher**  
Dedicated detection for AI coding agents (Claude Code, Codex, Gemini CLI) waiting for approval.

**Phase 7 — Safe Action Layer**  
With explicit consent, allow DeskKeeper to perform one-click actions (focus window, click known button) — not autonomous.

**Phase 8 — Team Layer (optional)**  
Shared dashboards. Team workflow monitoring. Async status sharing.

---

## Monetization Possibilities

- **DeskKeeper Free**: Core local detection, basic notifications
- **DeskKeeper Pro**: OCR, AI classifier, advanced rules, multi-monitor view
- **DeskKeeper Teams**: Shared dashboards, workflow templates, team notification routing
- **Enterprise**: Deployed locally with org-level policies, no cloud required

---

## Design North Star

A power user should see DeskKeeper and think: **"This is the tool I didn't know I was missing."**

Not another AI gimmick. A reliable, quiet, local-first system that has their back.
